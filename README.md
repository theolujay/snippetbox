Snippetbox is a server-rendered web app to share snippets of text -- quotes, quick messages, notes, love letters?... -- with expiration. It's a build-along project from the book **Let's Go: A Step-By-Step Guide to Creating Fast, Secure, and Maintainable Web Applications in Go** <sup>[1](https://lets-go.alexedwards.net/)</sup> by [Alex Edwards](https://github.com/alexedwards). I picked it up to learn the Go programming language and its conventional practices.

![Screenshot of Snippetbox homepage](homepage.png)

**Running Locally**

```bash
git clone https://github.com/theolujay/snippetbox
cd snippetbox
go run ./cmd/web
```
